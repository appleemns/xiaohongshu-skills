# 小红书视觉素材规格（参考）

> 与 xhs-image-production 技能配套。尺寸与规范以平台后台「上传提示/帮助中心」为准，此表为默认建议。

## 尺寸速查

| 素材 | 比例 | 建议像素 | 备注 |
|---|---|---|---|
| 商品主图 | 1:1 | ≥ 800×800 | 首图信息层级：主体居中、卖点 ≤ 3 个 |
| 商品副图 | 1:1 | ≥ 800×800 | 4-8 张：多角度/细节/场景/尺寸 |
| 详情图 | 1:1 / 长图 | 宽 ≥ 750 | 材质、规格、场景、售后 |
| 图文笔记封面 | 3:4 | 1242×1656 | 大字报风格，主利益点 ≤ 8 字 |
| 笔记内图 | 3:4 | 1242×1656 | 全篇统一比例，不留白边 |
| 视频笔记 | 9:16 | 1080×1920 | 前 3 秒钩子画面 |
| 活动海报 | 3:4 / 1:1 | 1242×1656 / 1080×1080 | 大促/话题活动 |
| 账号头图 | 按专业号规范 | 以后台提示为准 | 品牌主视觉 |
| 置顶/合集封面 | 3:4 | 1242×1656 | 与主页风格统一 |

## 封面大字报排版规范

- 主文案 ≤ 8 字，副文案 ≤ 12 字；主次层级清晰。
- 文案与商品主体不重叠遮挡；留白 ≥ 10%。
- 颜色 ≤ 3 个主色；对比度足够（小图可读）。
- 数字/价格用大字号（如「39 元」「第 3 代」）。

## 品牌调性（待固化）

- 店铺品牌调性待老板确认后在此固化（主色、字体、风格关键词），未固化前保持干净真实、不花哨。
- 所有对外图遵循小红书社区审美：真实、生活化、不过度精修。

## 文字合规（每次叠加必查）

- 禁：最/第一/顶级/100%/全网/国家级等绝对化用语。
- 禁：医疗功效暗示（祛痘、减肥、治疗等）。
- 禁：未授权品牌 Logo、名人肖像、影视截图。
- 字体：思源黑体 / 阿里巴巴普惠体等可商用字体。

## 归档规范

- 商品图：`data/products/<SKU>/<SKU>_<用途>_<版本>.jpg|png`
- 笔记封面：`data/notes/<日期>_<标题>_cover_<版本>.png`
- 活动素材：`data/analytics/` 或任务卡指定目录
- AI 生成图附 `.prompt.txt`（记录模型与 prompt，便于复现与审计）
