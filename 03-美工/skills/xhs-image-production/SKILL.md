# Image Production 图片制作（小红书版）

## 尺寸规格（按平台要求）

| 素材 | 比例/尺寸（建议） | 用途 |
|---|---|---|
| 商品主图 | 1:1，800×800 以上 | 商品详情首图（前台展示） |
| 商品副图 | 1:1，4-8 张 | 多角度/细节/场景 |
| 详情图 | 1:1 或长图 | 商品详情页 |
| 笔记封面（图文） | 3:4（1242×1656 建议） | 笔记首图，大字报风格 |
| 视频封面 | 9:16（1080×1920 建议） | 视频笔记封面 |
| 笔记内图 | 3:4 统一比例 | 正文配图 |
| 活动海报 | 3:4（竖版）或 1:1 | 大促/优惠券/话题活动 |
| 账号头图 | 按专业号规范 | 账号主页 |
| 置顶/合集封面 | 3:4 | 账号主页内容沉淀 |

## 制作流程

1. **明确需求**：读取任务卡（用途/尺寸/文案/商品 SKU），商品图需读取 `data/products/<SKU>/product-info.md` 与实拍原图。
2. **选风格**：按店铺品牌调性（待确认后固化）；商品图以真实产品为主，背景干净、光线自然。
3. **AI 出图/修图约束（沿用 TikTok 团队红线）**：
   - 不得修改原产品的尺寸、设计、配色、结构等核心外观特征。
   - AI 出图仅可做：背景优化、排版、文字叠加、光影/色彩微调。
   - AI 生成内容不得冒充实拍；涉及功能/认证/材质表达必须与 product-info 一致。
4. **文字叠加规范**：
   - 封面大字报：主利益点 ≤ 8 字大字 + 副文案 ≤ 12 字。
   - 无绝对化用语（最/第一/顶级）；无医疗功效暗示；无未授权品牌/名人元素。
   - 字体使用可商用字体（如思源黑体/阿里巴巴普惠体），不擅自使用版权字体。
5. **导出与命名**：
   - 命名：`<SKU>_<用途>_<版本>.jpg|png`（`sku001_main_v2.jpg`、`note_cover_3-4_v1.png`、`poster_double11_v1.png`）。
   - 归入 `data/products/<SKU>/` 或 `data/notes/`；AI 生成图附 prompt 记录（`<文件名>.prompt.txt`）。

## 合规自查（交付前必过）

- [ ] 产品核心外观未被篡改
- [ ] 无绝对化用语/虚假功效/医疗暗示
- [ ] 无未授权品牌/名人/版权元素；字体可商用
- [ ] 尺寸比例正确、清晰度达标（主图不糊、细节可见）
- [ ] 命名与归档规范

## 输出规范

- 向店长汇报：完成图清单（文件路径）+ 用途 + 版本号。
- 活动素材按任务卡优先级出图；主图/封面优化必须基于数据（见 xhs-main-image-ctr）。
