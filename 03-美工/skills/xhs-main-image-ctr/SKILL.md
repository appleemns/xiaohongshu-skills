# Main Image CTR 主图/封面点击率分析（小红书版）

## 适用对象

1. **商品主图**：曝光高、点击低（CTR 低于类目均值或 < 1%）→ 主图问题。
2. **笔记封面**：笔记曝光高、阅读低（阅读率 = 阅读/曝光 低于账号均值）→ 封面/标题问题。
3. 封面阅读正常、互动低 → 内容问题（转给运营，不在本技能范围）。

## 诊断流程（问题 → 诊断 → 改动 → 预期）

### 第 1 步 拉数据
- 商品：千帆数据中心商品分析 → 曝光/点击/CTR。
- 笔记：专业号后台 → 单篇笔记曝光/阅读/互动。
- 读取 `data/analytics/` 或 `data/manual/` 落盘数据。

### 第 2 步 分级诊断（对照参考）

| 现象 | 可能原因 | 优化动作 |
|---|---|---|
| 画面杂乱/信息过多 | 主卖点不突出 | 精简画面，突出 1 个核心卖点 |
| 利益点不清晰 | 文案太弱/太小 | 大字报式利益点（≤8 字） |
| 与搜索词不匹配 | 图与标题/关键词脱节 | 首图呼应标题关键词（场景/款式） |
| 竞品同质化 | 无差异化 | 加差异化标签（材质/设计/人群） |
| 真实感不足 | 疑似 AI 图/修图过度 | 用实拍、真实场景图 |
| 无信任感 | 缺细节 | 增加材质特写/尺寸对比/使用场景 |

### 第 3 步 输出优化方案
- 每张问题图输出：问题 → 诊断 → 改动点（具体）→ 预期提升（标注「预期」）。
- 出 A/B 方案：同一商品/笔记出 2 版封面/主图（差异集中在 1 个变量：卖点/色调/构图）。

### 第 4 步 重做与对比
- 按 xhs-image-production 规范重做图片，命名 `<SKU>_main_v2` / `note_cover_v2`。
- 上架/替换后跟踪 CTR 变化，把结果（前/后对比）回填任务卡与日报。

## 输出要求

- 优化报告：`问题 → 诊断 → 改动 → 预期` 四段式，写入任务卡「执行结果」或 `reports/`。
- 向店长汇报：问题图清单 / 改动摘要 / A/B 方案 / 需要老板确认的测试范围。

## 常见错误（避免）

- 不看数据凭感觉换图。
- 一次改多个变量导致无法归因。
- 修改产品核心外观（红线）。
- 不跟踪改后数据（无闭环）。
