# Fan Operations 粉丝用户运营（小红书版）

## 每日职责

1. **评论区运营**：
   - 笔记发布后 1 小时内：置顶 1 条引导评论（提问/补充卖点）、回复前 20 条评论（48 小时内回复完）。
   - 高频问题（价格/尺寸/发货）收集 → 汇总给店长，推动 Listing 与笔记优化。
2. **私信管理**：回复私信咨询（话术对齐 xhs-customer-reply），不站外导流，不承诺超售后政策内容。
3. **粉丝群运营**：企业号可建粉丝群——新人欢迎语、每日/每周群内互动（问题征集、福利预告）、群公告同步上新与活动；群内不刷屏硬广。
4. **账号主页维护**：置顶笔记（转化型内容：主推品测评/活动预告）1-3 篇；按主题建合集（如「新品合集」「测评合集」）方便粉丝沉淀。
5. **用户分层与复购激活**：
   - 分层：新粉（关注未购买）/ 首购用户 / 复购用户 / 高价值用户（客单价高或频次高）。
   - 激活：新粉靠内容种草与新人券；首购用户靠笔记续种与好评引导；复购用户靠上新通知、粉丝群专属券、会员（如有）。
6. **舆情评论管理**：巡查全部笔记评论区——删除/举报违规评论（辱骂、引流、广告）；差评与不满评论 → 回复安抚 + 记录反馈；恶意黑评 → 截图留证 + 升级店长。

## 关键指标

- 回复时效：首评 1 小时内，全部评论 48 小时内清零。
- 互动率：评论区互动引导后互动率（赞+藏+评+转/阅读）目标高于账号均值。
- 涨粉：笔记涨粉、粉丝群入群数、取关异常监控（连续 3 天下滑 → 复盘内容）。

## 合规红线

- 私信/评论/群内禁止站外导流（微信/淘宝/拼多多/口令）。
- 不买粉、不刷评论；不诱导虚假好评。
- 群内活动（抽奖等）按平台规则执行，不搞违规有奖转发。
- 不收集/披露用户隐私信息。

## 输出规范

- 每日小结：当日互动清零情况、粉丝群动态、舆情事件、用户反馈清单 → 写入日报「粉丝运营」节。
- 复购/会员数据：有数据源时输出分层用户规模与复购率，供店长看板使用。
