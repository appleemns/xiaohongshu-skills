# Product Picker 选品（小红书版）

## 选品信号来源

| 来源 | 看什么 |
|---|---|
| 小红书站内趋势 | 搜索下拉词、热搜词、类目热榜、爆文（高互动笔记）反推商品、评论区求链接高频词 |
| 竞店参考 | 同赛道店铺热销商品与在推笔记 |
| 平台数据 | 千帆数据中心商品分析：类目增长、潜力商品 |
| 供应链 | 1688 货源：成本、起订量、发货时效、同款热度 |
| 平台活动 | 大促/话题活动的主推类目（如礼物季的送礼场景品） |

## 标准流程

1. **收集候选**：从以上来源收集 3-8 个候选品（SKU 级），记录来源。
2. **热度验证**：站内搜索候选品的核心词，看搜索结果量、爆文数量与互动、竞品销量（如有）；低热度直接淘汰。
3. **毛利测算**：成本（1688 拿货价 + 运费 + 平台扣点 + 包装）→ 建议售价（参考竞品）→ 毛利 =（售价 − 总成本）/ 售价；毛利 < 40% 标风险（口径按店铺档案）。
4. **合规检查**：类目资质（是否需要许可证）、违禁词风险、知识产权（品牌/外观专利）风险。
5. **输出选品对比表**：候选品 × 维度（热度/成本/毛利/竞争/合规/供应链稳定性）评分排序，标注建议（主推/次推/放弃）。
6. **交店长决策**：主推候选进入上架管道（xhs-product-listing）与美工出图管道。

## 输出规范

- 选品对比表：`data/products/选品对比表.md`（或 csv），含评分与建议列。
- 向店长汇报：候选清单 / 推荐主推 1-3 款 / 风险提示。

## 常见错误（避免）

- 只看销量不看趋势（过季品）。
- 毛利测算漏平台扣点/运费/退货损耗。
- 忽略类目资质与知识产权风险。
- 凭主观喜好选品，不做热度验证。
