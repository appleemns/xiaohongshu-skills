# Product Listing 商品上架与维护（小红书版）

## 上架标准流程

1. **商品信息准备**：读取商品资料（`data/products/<SKU>/product-info.md`：材质/规格/卖点/实拍图），确认类目与属性。
2. **标题撰写**：按 `references/listing-templates.md` 模板：核心词 + 卖点 + 场景词 + 属性词，长度符合平台要求，覆盖用户搜索习惯（小红书用户爱搜「怎么搭/测评/礼盒」等长尾词）。
3. **卖点与详情**：3-5 条卖点（每条约 15-25 字，突出差异化）；详情描述含材质、尺寸、适用场景、售后说明。
4. **价格与毛利复核**：计算到手价 = 售价 − 券/平台扣点；毛利 =（到手价 − 成本 − 运费 − 平台费）/ 到手价；毛利 < 40% 时标注风险并报店长（口径按店铺档案）。
5. **图片校验**：主图 1:1（800×800 以上）、副图 ≥ 4 张、详情图；检查是否有违规元素（绝对化用语/未授权品牌/功效暗示），无则退回美工。
6. **库存与运费模板**：填写库存、运费模板、发货时效；1688 一件代发场景核对供应商库存。
7. **提交审核与跟进**：提交后每日跟进审核状态；被驳回 → 读取驳回原因 → 修正后重提。

## Listing 优化（低转化商品）

- 触发：曝光高、转化低 / CTR 正常但加购转化低。
- 检查项：标题关键词相关性、首图信息层级、卖点是否清晰、价格与竞品对比、评价/问大家是否有负面、商品是否挂载到在推笔记。
- 优化后记录改动，交店长验收。

## 合规自查（发布前必过）

- 无绝对化用语（最/第一/顶级/100%）。
- 无虚假功效/成分/材质宣称；无医疗功效暗示。
- 价格、库存、发货时效与实际一致。
- 图片无未授权品牌/名人/版权元素。

## 输出规范

- 上架任务：产出 `data/products/<SKU>/listing-copy.md`（标题/卖点/详情/价格/毛利计算表）+ 任务卡回填。
- 审核跟进：日报「商品」节记录审核状态与驳回原因。
