# 小红书 Listing 文案模板（参考）

> 与 xhs-product-listing 技能配套。标题与卖点面向小红书搜索与种草场景，长度与字段以后台实际为准。

## 标题结构（3 选 1，嵌关键词）

1. **核心词 + 卖点 + 场景**：`[类目词] [人群/场景] [核心卖点]`
   例：`真丝发圈 温柔风 上班通勤不勒头发`
2. **测评/对比式**：`[商品] 测评 | [对比对象] 我为什么选它`
3. **送礼/场景式**：`[场景节日] 送[对象]的[类目]清单 质感很重要`

- 核心关键词放标题前部；可带 1 个长尾词（怎么搭/多少钱/适合谁）。
- 不用夸张词与绝对化用语；字数符合平台限制。

## 卖点写法（3-5 条，每条 15-25 字）

- 格式：`卖点标签：具体描述（可感知）`
  - 材质：`真丝面料：16 姆米重磅，贴头皮不毛躁`
  - 场景：`通勤友好：扎一天不勒不痛，拆下无痕`
  - 差异：`独特设计：宋锦纹样，戴出去不撞款`
  - 售后：`七天无理由：尺码不合适可退换`
- 避免空洞词（"品质好""高大上"），全部用可感知描述。

## 详情描述结构

1. 一句话定位（这是什么、给谁用）
2. 规格参数（材质/尺寸/重量/颜色）
3. 使用场景与搭配建议（2-3 条）
4. 售后与发货说明（时效/退换政策）
