# Note Publishing 笔记撰写与发布（小红书版）

## 笔记类型

| 类型 | 规格 | 适用 |
|---|---|---|
| 图文笔记 | 封面 3:4（1242×1656 建议），1-10 张图 | 种草、测评、清单、教程（默认主力） |
| 视频笔记 | 9:16 竖屏（1080×1920 建议），15-60 秒 | 开箱、使用过程、场景演绎 |

## 撰写标准流程

1. **定主题与目标词**：结合内容日历/活动主题/商品卖点，确定 1 个核心关键词 + 2-3 个长尾词（用户搜索习惯：怎么搭/测评/多少钱/礼盒/攻略）。
2. **标题**：按 `references/note-templates.md` 标题公式（痛点+解决方案 / 数字+结果 / 场景+人群），嵌入核心关键词，20 字内为宜。
3. **正文结构**（图文）：开头 3 行内给结论/吸引点 → 分段讲卖点与使用场景（真实、具体）→ 价格与渠道信息 → 结尾互动引导（收藏/提问）。禁用硬广感，走「真实分享」口吻。
4. **话题标签**：3-5 个，包含 1 个品牌自建话题 + 类目大词 + 场景词 + 热点词（不蹭无关热点）。
5. **商品卡片挂载**：笔记发布时挂载对应商品卡片（如有上架商品）；商品与笔记内容强相关。
6. **图片/封面**：封面 3:4 大字报风格（利益点一眼可见），由美工按 `xhs-image-production` 提供或复用商品图。
7. **发布时间**：默认 12:00-13:00 / 18:00-22:00，按账号粉丝活跃数据迭代。
8. **发布**：经创作服务/专业号后台发布；发布后 1 小时内在评论区引导互动（置顶引导评论、回复提问）。

## 薯条投放建议（不擅自投）

- 发布 2-4 小时后评估自然流量：曝光/阅读/互动率达标（如阅读率 > 8%、互动率 > 3%，阈值按账号数据迭代）→ 输出薯条投放建议（预算、时长、定向），交老板拍板。
- 不达标笔记：先优化封面/标题再决定是否补救，不盲目加热。

## 合规自查（发布前必过）

- 无绝对化用语；无虚假功效/成分宣称。
- 与达人合作的商业笔记：报备走蒲公英、笔记带「广告」标注；自营笔记保持真实分享口吻。
- 不站外导流（不放微信/淘宝/拼多多等联系方式与引导）。
- 不蹭无关热点、不搬运他人原创内容。

## 输出规范

- 文案存档：`data/notes/YYYY-MM-DD-标题.md`（含标题/正文/话题/发布计划）。
- 发布后回填：任务卡记录笔记链接、发布时间、首日数据（曝光/阅读/互动）。
- 日报「笔记」节：当日发布清单 + 前日笔记数据迭代结论。
