# 小红书笔记模板（参考）

> 与 xhs-note-publishing 技能配套。口吻要求：真诚、具体、像真人分享，避免硬广感。

## 标题公式（选 1）

| 公式 | 示例 |
|---|---|
| 痛点+解决方案 | `头发总炸毛？换这个真丝发圈试试` |
| 数字+结果 | `通勤 3 个月，这只包每天背都不腻` |
| 场景+人群 | `打工人桌面好物｜均价不过百` |
| 对比/测评 | `200 和 2000 的丝巾差别有多大` |
| 提问式 | `给妈妈挑礼物，这份清单靠谱吗` |

## 图文笔记正文结构

1. **开头（3 行内）**：给结论/钩子——为什么值得看（`最近被问最多的 XX，实测一周来交作业`）。
2. **主体（分段）**：每段 1 个卖点 + 使用场景 + 具体细节（颜色/手感/尺寸/气味），配图一一对应。
3. **价格与渠道**：价格区间 + `店铺：XX`（可挂商品卡片则标注）。
4. **结尾互动**：`你们还想看 XX 吗？评论区告诉我` / `先收藏，用到再来谢我`。

## 视频笔记脚本结构（15-60 秒）

- 0-3 秒：钩子（问题/悬念/效果前置）
- 3-15 秒：展示主体（开箱/细节/使用过程）
- 15-45 秒：卖点逐条 + 场景
- 结尾：价格/店铺 + 引导关注收藏

## 话题标签规则

- 3-5 个：1 个品牌自建话题（如 `#XX品牌好物`）+ 1-2 个类目大词（如 `#发圈`）+ 场景词（`#通勤好物`）+ 热点词（蹭相关度高的，不蹭无关）。
- 标签放正文末尾，不堆砌、不重复。

## 发布后 1 小时动作

- 置顶引导评论（提问或补充信息）。
- 回复前 20 条评论；回复完高频问题后，把问题清单传给运营汇总。

## 合规自查清单（发布前勾选）

- [ ] 无绝对化用语（最/第一/顶级/100%）
- [ ] 无虚假功效/成分宣称，无医疗暗示
- [ ] 无站外导流（微信/淘宝/拼多多等）
- [ ] 商业合作已报备/标注广告（如适用）
- [ ] 图片文字无违规（未授权品牌、版权元素）
- [ ] 不搬运抄袭他人内容
