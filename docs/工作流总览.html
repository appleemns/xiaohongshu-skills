二、每日运营 SOP（完整覆盖）

  1. 第 0 步 登录检查（店长）：千帆商家后台登录态检查，失效提醒老板扫码。
  2. 早盘数据看板（店长+运营）：GMV / 订单 / 客单价 / 退款 / 访客 / 转化 / 笔记数据 / 涨粉 → 定 P0/P1/P2 → 更新 data/dashboard.json。
  3. 商品运营（运营）：上架与审核跟进、Listing 优化、库存补货、选品。
  4. 内容运营（运营）：按内容日历撰写发布笔记（图文/视频）、关键词布局、话题标签、商品卡片、发布后评论区引导、薯条投放建议。
  5. 活动策划（店长+运营）：平台大促日历、优惠券/满减、直播、话题活动 → 拆任务给美工/运营/客服。
  6. 美工：商品图/笔记封面/活动海报/账号宣传图 + 主图与封面 CTR 诊断优化。
  7. 客服与达人（客服）：千帆消息清零、差评与评论舆情、蒲公英报备合作（优先）+ 私域邀约、寄样审批跟进。
  8. 晚报日报（店长）：汇总完成项 / 关键数据 / 待拍板清单 / 明日计划 → 同步数据分析平台。

四、任务与数据流转

老板指令→ 店长拆解→ 任务卡 tasks/inbox/<角色>/→ 员工执行（单会话全包）→ 店长验收→ 归档 tasks/archive/→ 日报 + dashboard.json

数据来源：千帆商家后台浏览器直连（网页读取/导出 CSV → data/manual/）；内容数据来自专业号后台；达人数据来自蒲公英。所有数据标注口径。
