# 数据接入指南（千帆浏览器直连 · 默认）

> 小红书店铺数据默认通过豆包浏览器直连千帆商家后台获取，与 TikTok 团队 Seller Center 直连模式一致。
> 官方开放平台 API 为可选升级，需要高频稳定拉数时再启用。

## 一、默认方式：浏览器直连（每日第 0 步）

1. 店长/运营通过豆包浏览器能力打开千帆商家后台：https://seller.xiaohongshu.com
2. 首次登录：老板扫码授权；登录态长期保留，后续自动进入。
3. 每日开工先做登录检查（xhs-qianfan-web 技能）；失效 → 提醒老板扫码。
4. 数据读取/导出：
   - 「数据中心」：GMV、订单、流量、转化 → 在线查看或导出 CSV。
   - 「商品管理」：商品表现、审核状态。
   - 「消息中心 / 评价管理」：客服消息、差评。
   - 专业号后台：笔记数据、粉丝数据。
   - 蒲公英（pgy.xiaohongshu.com）：达人合作数据。
5. 导出 CSV 移动到 `data/manual/YYYY-MM-DD_<模块>.csv`，可用 `api/xhs_client.py --import-csv` 归一化。

## 二、可选升级：官方开放平台 API

> 需要企业资质与 App 审核；未开通前不要编造 API 能力。启用流程：

1. 在小红书开放平台（open.xiaohongshu.com）注册应用（企业资质），申请商家数据相关接口权限。
2. 获取 `app_id` / `app_secret`，填入 `api/config.example.json` → 另存为 `api/config.json`（不提交版本库）。
3. 修改 `api/xhs_client.py` 中 `pull_daily()` 占位实现，按开放平台文档对接订单/商品/分析接口。
4. 运行 `python api/xhs_client.py --pull-daily` 自动拉数落盘 `data/orders|analytics/`。

## 三、口径标注规则

- 所有数据标注：`千帆网页读取` / `手动导出` / `官方 API` / `估算`。
- 千帆部分报表 T+1，昨日数据上午才完整；早盘拉数注意时间口径。
- 无法获取的数据明确告知老板，不编数字。

## 四、安全红线

- 凭证不落盘（扫码优先）；`config.json` 不进任何共享/版本库。
- 只操作本店账号；不代他人操作。
- 触发验证码/风控 → 立即停止操作并人工介入，不重试。
