# 任务卡模板（任务流转协议）

所有任务卡使用以下统一格式。店长派活时按此生成；执行方回填「执行结果」；完成后由店长移入 `tasks/archive/`。

**文件名**：`YYYYMMDD-<序号>-<角色>-<任务简述>.md`
**示例**：`20261002-01-运营-发布2篇新品种草笔记.md`

---

# 任务卡

- 任务ID：YYYYMMDD-序号
- 负责人：01-店长 / 02-运营 / 03-美工 / 04-客服
- 派发人：01-店长
- 优先级：P0（当日必须） / P1（本周内） / P2（可排期）
- 截止时间：YYYY-MM-DD HH:MM

## 目标
（一句话说清要达成什么）

## 输入数据
（列出需要读取的数据/文件路径；没有则写「无」）

## 要求与步骤
（要点式列出执行步骤，并引用对应技能 SKILL.md；发布/对外类任务附合规自查项）

## 交付物
（产出文件的路径与格式）

## 验收标准
（可勾选清单）
- [ ] 1. ...
- [ ] 2. ...

- 关键数据/输出：
- 遗留问题：
