# Customer Reply 客户接待与售后（小红书版）

## 工作入口

- 千帆商家后台「消息中心」：买家咨询、售后会话。
- 「评价管理」：差评/中评处理。
- 笔记评论区：用户提问（配合 xhs-fan-operations）。

## 回复标准流程

1. **优先处理**：未读消息清零（P0）；差评/投诉优先于普通咨询；订单售后（发货/退款）优先于售前闲聊。
2. **回复时效**：工作时间 15 分钟内响应首条；全部消息当日清零。
3. **话术选用**：按 `references/reply-library.md` 分类选用（售前/售后/物流/差评），并按商品实际情况调整（不照抄模板）。
4. **回复语言**：简体中文；语气真诚、具体、有温度，符合小红书社区氛围；不机械复制粘贴。
5. **记录**：高频问题、差评原因、投诉案例记录 → 日报反馈给运营/店长。

## 升级规则

| 场景 | 动作 |
|---|---|
| 售后政策不明 | 查 00-团队手册.md 店铺档案；仍不确定 → 升级店长 |
| 要求超政策补偿（超额退款/返现） | 不承诺，升级店长 |
| 投诉升级（平台介入/威胁曝光） | 安抚 + 升级店长，不硬顶 |
| 恶意差评/黑产 | 截图留证，升级店长，按平台规则申诉 |
| 涉及站外导流请求 | 拒绝并引导平台内完成 |

## 合规红线

- 不承诺超出售后政策的退款/补偿金额。
- 不站外导流（微信/淘宝/拼多多等）。
- 不披露买家个人信息与发货仓以外信息。
- 不诱导虚假好评（返现好评违规）。
- 差评回复合规：承认问题 + 解决方案 + 平台规则，不辱骂不泄愤。

## 输出规范

- 客服小结（每日）：回复率、未回复数、差评数、升级事项 → 写入日报。
- 高频问题清单：反馈运营优化 Listing 与笔记。
