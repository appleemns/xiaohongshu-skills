# Influencer Outreach 达人邀约与合作（小红书版）

## 合作双路径（蒲公英优先）

| 路径 | 适用 | 流程要点 |
|---|---|---|
| 蒲公英报备合作（优先） | 已开通专业号/品牌资质 | 蒲公英平台发布任务 → 达人报名/定向邀约 → 下单报备 → 寄样 → 达人发布（笔记带「广告」标注）→ 数据回传 |
| 私域邀约（兜底） | 未入驻/无资质、或低成本合作 | 私信/评论区邀约 → 谈置换或付费 → 寄样 → 达人发布（注意：未报备商业笔记有限流风险，文案须软） |

## 标准流程

1. **定需求**：按店长/运营内容计划确定：产品（SKU）、笔记形式（图文/视频）、预算档位（样品/佣金）、目标粉丝量级（默认 1k-50k 中小达人为主）。
2. **找达人**：
   - 蒲公英：按类目/粉丝量/互动率筛选；参考历史数据（报价、爆文率）。
   - 私域：站内搜竞品相关笔记作者、同类目话题高互动作者、粉丝群/评论区活跃用户。
3. **生成邀约话术**：按 `references/outreach-templates.md`（蒲公英版/私域版），突出：产品卖点、合作形式、寄样/报酬、发布要求。
4. **邀约与跟进**：按跟进表状态机推进：**邀约 → 回复 → 寄样 → 内容 → 出单**；48 小时未回复 → 跟进一次；超过 7 天无进展 → 标记暂停。
5. **寄样审批**：寄样申请（达人信息/样品价值/预期产出）提交店长/老板审批，**未批不寄**；审批留痕。
6. **寄样与内容跟进**：寄出后跟踪物流签收；催内容（礼貌提醒，不施压）；内容发布前过合规检查（广告标注/无违规词）。
7. **数据复盘**：内容发布后 7 天收集：曝光/阅读/互动/带货 GMV/涨粉 → 更新跟进表 → 周报输出达人出单 Top。

## 达人跟进表（data/influencers/达人跟进表.md）

| 字段 | 说明 |
|---|---|
| 达人名称/主页链接 | 唯一标识 |
| 粉丝量级 / 互动率 | 筛选时记录 |
| 合作路径 | 蒲公英报备 / 私域 |
| 状态 | 邀约→回复→寄样→内容→出单 / 暂停 / 放弃 |
| 寄样 SKU / 样品价值 | 审批留痕 |
| 发布链接 / 数据 | 曝光/阅读/互动/GMV |
| 备注 | 风险（刷量嫌疑/履约差） |

## 合规红线

- 商业合作优先报备；未报备笔记不得有明显硬广（防限流）。
- 不私下答应额外佣金/样品；佣金与寄样标准交老板确认。
- 不买假粉、不刷数据；发现达人刷量嫌疑 → 标记风险并停止合作。
- 不代达人操作账号；不引导站外交易。

## 输出规范

- 每日小结：新增邀约数、各状态达人数量、待审批寄样 → 写入日报。
- 周复盘：出单达人 Top10、ROI（带货 GMV/样品+佣金成本）、风险清单。
