# Campaign Planner 活动策划（小红书版）

## 活动类型清单

| 类型 | 说明 | 典型玩法 |
|---|---|---|
| 平台大促 | 小红书全域电商大促节点（见 references/campaign-calendar.md） | 报名大促、大促价、运费险、跨店满减 |
| 店铺促销 | 店铺自主营销 | 优惠券（店铺券/商品券）、满减、限时折扣、新人券 |
| 直播专场 | 店铺直播或达播 | 直播预告笔记、直播间专属券、抽奖 |
| 话题活动 | 内容侧营销 | 品牌话题挑战、UGC 征集、抽奖笔记 |
| 内容节点 | 季节/热点内容营销 | 春季焕新、秋季上新、节日种草（情人节/母亲节等） |

## 标准流程

1. **核对营销日历**：读取 `references/campaign-calendar.md`，确认当前/近期节点与报名截止时间；平台规则以后台「营销活动中心」实际为准，不确定先查后台。
2. **评估方案**：确定参与形式（大促报名/优惠券/直播/话题）与预算档位（优惠券面额、薯条预算、样品数量）；涉及价格/预算 → 列方案交老板拍板，不擅自执行。
3. **拆解任务**：活动任务拆解为任务卡——
   - 素材（海报/主图/直播间视觉）→ 03-美工
   - 商品配置（活动价/券/库存）/笔记预告 → 02-运营
   - 客服话术（大促咨询/售后高峰应对）→ 04-客服
4. **配置与上线**：方案确认后由对应员工执行；店长跟踪各环节完成度。
5. **复盘**：活动结束后输出复盘（GMV 增量、券核销率、笔记曝光、达人产出、成本），写入周报。

## 促销力度与毛利红线

- 活动价不得击穿毛利底线（默认毛利 ≥ 40% 口径，按店铺档案）。
- 优惠券/满减叠加后的到手价，需运营按 `xhs-product-listing` 毛利复核后再发布。
- 大促报名与平台规则变更，以千帆后台「营销活动中心」展示为准。

## 输出要求

- 活动方案文档：目标 / 玩法 / 预算（含老板拍板项）/ 任务卡清单 / 验收标准 / 复盘计划。
- 方案输出到 `reports/` 或任务卡；向老板汇报时结论先行、附「待拍板」清单。

## 常见错误（避免）

- 未经老板确认就配置价格/优惠券/投薯条。
- 忽略报名截止时间（错过平台大促窗口）。
- 活动结束不复盘、不沉淀数据。
