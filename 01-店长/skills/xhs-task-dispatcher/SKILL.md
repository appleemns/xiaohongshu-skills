# Task Dispatcher 任务派发（小红书团队版）

店长所有派活动作必须通过本技能生成标准任务卡，保证留痕与可验收。

## 标准流程

1. **拆解**：把老板指令拆成原子子任务；每个子任务只有一个负责人（跨员工任务拆成多张卡，如「上新」= 美工出图卡 + 运营上架卡）。
2. **生成任务卡**：读取模板 `tasks/任务卡模板.md`，按模板生成，命名 `YYYYMMDD-序号-角色-简述.md`（序号当日递增）。
3. **派发**：写入 `tasks/inbox/<角色>/`（01-店长 / 02-运营 / 03-美工 / 04-客服）。
4. **优先级规则**：
   - P0 = 当日必须（影响销售/处罚/审核时效/笔记发布窗口）
   - P1 = 本周内（常规上新、笔记优化、达人邀约）
   - P2 = 可排期（素材库、复盘类）
5. **执行与回填**：执行方完成后回填「执行结果」四要素（完成情况/关键数据/遗留问题/时间）。
6. **验收与归档**：按验收标准逐条核对；通过 → 移入 `tasks/archive/`；不通过 → 打回并注明原因。

## 输出格式要点

- 任务卡内必须包含：输入数据路径、引用技能路径（`<角色>/skills/<技能>/SKILL.md`）、交付物路径、可勾选验收标准。
- 交付物路径写绝对路径或相对团队根目录路径，避免歧义。
- 涉及小红书平台操作的卡（发笔记/上架/回复买家/邀约达人）须附合规自查项（见 00-团队手册.md 第 7 节）。

## 常见错误（避免）

- 一张卡塞两个负责人。
- 验收标准写"完成"等模糊词，必须可勾选、可量化。
- 忘记回填执行结果就归档。
- 发布类任务卡未附合规自查清单。
