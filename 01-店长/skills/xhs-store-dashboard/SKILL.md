# Store Dashboard 店铺数据看板（小红书版）

## 数据来源（默认千帆浏览器直连）

1. **千帆商家后台网页读取/导出（默认）**：经豆包浏览器登录后，在「数据中心」读取订单/商品/流量数据或导出 CSV → `data/manual/`（可用 `api/xhs_client.py --import-csv` 归一化），标注「网页读取 / 手动导出」。登录检查按 `xhs-qianfan-web` 技能。
2. **内容数据**：专业号后台/创作服务平台读取笔记数据（曝光/阅读/互动/涨粉）与粉丝数据（浏览器直连）。
3. **官方 API（可选升级）**：启用后运行 `api/xhs_client.py --pull-daily` 拉取订单/商品/分析数据，落盘 `data/orders|products|analytics/`。
4. 三者都无 → 明确告知老板缺数据，不编数字。

## 核心指标定义（口径统一）

| 指标 | 定义 |
|---|---|
| GMV | 已支付订单金额合计（含/不含运费按数据源口径注明） |
| 订单量 | 已支付订单数 |
| 客单价 | GMV / 订单量 |
| 访客数 | 店铺/商品页访客数（口径按数据源） |
| 转化率 | 下单买家 / 访客 × 100%（或按数据源口径） |
| CTR | 商品点击 / 曝光 × 100%（主图口径）；笔记封面点击 = 阅读 / 曝光 × 100% |
| 退款率 | 退款订单 / 总订单 × 100% |
| 互动率 | （赞+藏+评+转）/ 阅读 × 100%（笔记口径） |
| 涨粉 | 当日新增粉丝数 |

## 看板结构（写入 reports/日报/YYYY-MM-DD.md 或周报）

1. **经营总览**：GMV、订单量、客单价、退款率、访客数、转化率（环比昨日/上周同日）。
2. **商品表现 Top/Bottom**：曝光/点击/CTR/转化/GMV，Top5 与 Bottom5。
3. **笔记表现**：曝光/阅读/互动率/涨粉 Top5 与 Bottom5；内容类型（图文/视频）对比。
4. **粉丝数据**：总粉丝、当日涨粉、粉丝画像变化（如有）。
5. **预警区**：零曝光、低 CTR（<1% 标红）、断货、高退款、差评、笔记限流/违规提示。
6. **达人表现**（周报维度）：蒲公英/私域出单达人 Top、邀约进度。
7. **口径声明**：数据来源（网页读取/手动导出/API/估算）+ 时间范围。

## 更新数据分析平台

- 每日晚报前，把当日汇总写入 `data/dashboard.json`（schema 见 `data/README.md`），使 `docs/数据分析平台.html` 反映最新数据。
- dashboard.json 字段与日报段落一一对应：daily（经营序列）、products（商品）、notes（笔记）、followers（粉丝）、influencers（达人）、alerts（预警）。

## 预警规则

- 商品 CTR < 1% 且曝光 > 1 万 → 推给 03-美工 出主图优化任务卡。
- 笔记曝光高、阅读低（封面问题）→ 推给 03-美工 出封面优化任务卡；阅读高、互动低 → 推给 02-运营 优化内容与评论区引导。
- 库存 < 3 天销量 → 推给 02-运营 出补货清单。
- 退款率 > 5% 或新增差评 → 日报「风险」节置顶。
- 涨粉连续 3 天下滑 → 推给 02-运营 复盘内容节奏与话题。

## 输出要求

- 数字一律保留两位小数；环比缺基线时写「—」不写 0。
- 结论先行：第一行给「今日结论（好/坏/平 + 一句原因）」。
