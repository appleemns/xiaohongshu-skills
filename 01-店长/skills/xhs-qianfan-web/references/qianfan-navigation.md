# 千帆后台导航速查（小红书版）

> 与 xhs-qianfan-web 技能配套使用。路径以实际后台界面为准，若找不到对应入口，用后台搜索框或帮助中心定位。

## 后台入口

| 平台 | 地址 | 用途 |
|---|---|---|
| 千帆商家后台 | seller.xiaohongshu.com | 商品/订单/数据/客服/营销 |
| 专业号创作服务 | 千帆后台「创作」或专业号主页进入 | 笔记发布、笔记数据、粉丝数据 |
| 蒲公英 | pgy.xiaohongshu.com | 达人报备合作 |

## 各模块位置（常见路径）

1. **数据中心**：侧边栏「数据中心 / 生意参谋」→ 今日/昨日概览、流量分析、商品分析、转化漏斗；支持日期筛选与导出。
2. **商品管理**：侧边栏「商品」→ 商品列表、新建商品、审核状态、库存管理、运费模板。
3. **订单管理**：侧边栏「订单」→ 订单查询、发货、售后/退款处理。
4. **消息中心**：侧边栏「消息 / 客服」→ 买家咨询列表、回复窗口、历史会话；差评在「评价管理」。
5. **营销中心**：侧边栏「营销」→ 优惠券、满减、大促报名、直播营销位。
6. **直播**：侧边栏「直播」→ 直播间管理、商品挂载、优惠设置（如已开通直播）。
7. **账号/资质**：「设置」→ 店铺信息、专业号认证状态、资质与保证金。

## 数据导出步骤（通用）

1. 进入对应模块 → 设置日期范围（默认昨日/近7天）。
2. 点击「导出 / 下载报表」→ 选择 CSV/Excel。
3. 下载文件移动到 `data/manual/YYYY-MM-DD_<模块>.csv`。
4. 无法导出时截图关键数据，人工录入标注「网页读取」。

## 常见问题

- **找不到导出按钮**：部分报表仅支持在线查看 → 用「网页读取」口径，截图或摘录关键数字。
- **店铺区域/账号不对**：核对左上角店铺名与账号，企业店可能有多个子账号。
- **数据延迟**：千帆部分报表 T+1，昨日数据上午才完整，早盘拉数注意口径。
