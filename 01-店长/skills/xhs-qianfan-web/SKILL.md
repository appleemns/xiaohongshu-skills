# 千帆商家后台 · 登录与网页操作（小红书版）

## 登录入口

- 千帆商家后台：https://seller.xiaohongshu.com （商家平台/数据中心/商品管理/订单/客服消息）
- 内容后台：专业号创作服务平台（笔记数据/粉丝数据，入口在千帆后台或专业号主页）
- 蒲公英平台：https://pgy.xiaohongshu.com （达人报备合作，需专业号/品牌资质）
- 首次登录：老板扫码授权；登录态长期保留；失效时提醒老板重新扫码。

## 登录检查（每日第 0 步）

1. 打开千帆后台，确认登录态与当前店铺（企业店）一致。
2. 登录态失效 → 停止数据类任务，提醒老板扫码，其余不依赖后台的任务照常推进。
3. 触发验证码/风控 → 立即停止操作并人工介入，不重试。

## 常用操作入口

| 模块 | 操作 |
|---|---|
| 数据中心 | 拉取昨日 GMV/订单/流量/转化；导出 CSV → data/manual/ |
| 商品管理 | 上架/编辑/审核商品、库存、运费模板（运营操作） |
| 订单管理 | 订单查询、发货、退款处理（客服/运营操作） |
| 消息中心 | 买家咨询/售后回复（客服操作） |
| 营销中心 | 优惠券、满减、大促报名（店长确认后运营配置） |
| 直播中控 | 直播间商品与优惠设置（如有直播） |
| 创作服务/专业号后台 | 笔记发布、笔记数据、粉丝数据（运营操作） |
| 蒲公英 | 达人合作：报备笔记下单、寄样、数据回传（客服操作） |

## 导出与落盘规范

- 报表导出 CSV 放 `data/manual/YYYY-MM-DD_<模块>.csv`。
- 可用 `api/xhs_client.py --import-csv <文件>` 归一化到 `data/orders|analytics/`。
- 所有数据标注口径：网页读取 / 手动导出 / API / 估算。

## 安全红线

- 凭证不落盘（扫码优先）；只操作本店账号；不代他人操作。
- 不在后台执行未经店长确认的价格/优惠/上下架操作。
- 网页操作失败时读取报错并修正；连续失败两次换路径，不无限重试。

## 操作失败的处理

- 页面加载失败/元素定位失败：重新截图观察页面状态后重试。
- 数据页空白：检查店铺区域/日期筛选是否正确。
- 平台风控（验证码/限制）：停止操作，报告店长，人工介入。
